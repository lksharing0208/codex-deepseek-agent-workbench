# 五类场景的 Skills、Scripts、MCP 通用配置矩阵

## 通用基线
| 工具类型 | 通用建议 | 选择标准 |
|---|---|---|
| Skills | 任务拆解、研究与证据、质量审查、交付报告 | 复用流程和标准，不绑定单一供应商 |
| Scripts | 校验、转换、批量处理、计算、测试 | 输入输出明确、可重复运行、有失败码 |
| MCP | 文档/网页检索、知识库、代码托管、文件系统、业务系统 | 来源可信、权限最小化、调用可审计 |
| Plugins | 跨项目分发 Skills/MCP 组合 | 明确依赖、版本、权限和安装方式 |
| 子 Agent | 研究、执行、审查、领域专家 | 任务边界清晰，交付可验证 |

## 场景选型
| 场景 | 推荐 Skills | 推荐 Scripts | MCP / 外部连接 | 高风险控制 |
|---|---|---|---|---|
| 编程 | 仓库探索、功能实现、故障定位、代码审查、测试与发布 | lint、单测、构建、依赖审计、差异检查 | GitHub、官方技术文档、Issue/PR、项目知识库 | 不自动推送、合并、部署或删除 |
| 短剧 | 受众定位、选题、人物设定、分集结构、剧本、分镜、连续性审查 | 时长估算、角色一致性、分集格式、资产清单 | 资料检索、授权素材库、文档/表格、图像/视频平台 | 标注版权；发布、采购和授权需确认 |
| 写作 | 研究简报、提纲、风格适配、事实核查、编辑校对 | 字数统计、格式检查、链接检查、术语一致性 | 搜索/浏览、官方/学术资料、知识库、文档协作 | 不编造引用；敏感资料不外传 |
| 金融 | 市场研究、财报提取、指标定义、情景分析、风险审查、交易复盘 | 数据校验、指标计算、回测、风险统计、时间戳检查 | 可信行情/财务数据、公告披露、组合只读数据 | 默认只读；无授权不交易；不把估算当实时行情 |
| 法律 | 司法辖区识别、法规检索、合同审查、版本差异、风险备忘录 | 条款编号、日期/金额抽取、文档差异、引用检查 | 官方法律数据库、法院/监管网站、合同库 | 保密；不自动发送、签署或提交文件 |

## MCP 配置策略
1. 只配置实际需要的服务，不为数量而启用 MCP。
2. 每个服务注明用途、数据范围、读写权限、认证方式、超时/失败策略和负责人。
3. 对公开信息优先只读检索；连接个人账户、内部数据库、金融账户或客户文档前取得明确授权。
4. MCP 服务名、参数和 URL 必须以服务官方文档为准；模板不编造第三方服务器地址。
5. 不同运行环境的 MCP 配置格式可能不同，按当前 Codex 版本和插件规范选择并实际验证。
6. 模型能够生成工具调用请求，不代表运行环境已经连接 MCP 或拥有工具权限。

## DeepSeek 配置边界
DeepSeek 官方文档说明 OpenAI 兼容 API 地址为 https://api.deepseek.com。模型名称、能力和价格可能更新，应以官方文档为准。模型连接独立于场景；切换场景只改变规则、Skills、提示词和经批准的工具集合。
