# Full Closed Loop

A. Intake: goal, current/expected behavior, constraints, exclusions, acceptance criteria, risk.
B. Inspect/plan: read rules/code/tests/config; use Explorer and Architect for complex work; identify rollback.
C. Implement: bounded changes, existing conventions, success/boundary/failure tests.
D. Validate: narrow tests then broad checks; run `bash scripts/validate.sh`; record exact results.
E. Review: correctness, integrity, security, auth, retries/idempotency, concurrency, compatibility, observability, tests, secrets. Fix findings and rerun checks.
F. Deliver: summary, changed files, tests/results, assumptions, risks, gaps, next action. No push/deploy without approval.

Final report template:
```text
结果：...
变更文件：...
验证命令与结果：...
风险/假设：...
未完成项：...
建议下一步：...
```
