# 编程安全审查

检查输入校验与注入、身份认证/授权/租户隔离、秘密信息与日志脱敏、网络请求与 SSRF、SQL/事务/并发、文件上传与权限、依赖漏洞/许可证、默认配置与审计日志。

## 输出
按严重度列出问题，每项包含文件/位置、触发条件、影响、证据和修复建议。没有发现问题时说明审查范围，不承诺“绝对安全”。

## 边界
不在未授权环境进行攻击测试；不读取或输出真实凭证；不将未经验证的扫描器结果直接当作已确认漏洞。
