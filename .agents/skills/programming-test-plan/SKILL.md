# 编程测试计划

## 步骤
1. 读取项目测试说明和现有测试模式。
2. 将验收标准转成正向、边界、异常和回归用例。
3. 优先新增能稳定复现问题的测试，再实现或验证修复。
4. 选择最小但足够的测试集；安全、数据迁移、并发或接口变更需增加专项检查。
5. 运行命令并记录退出码、摘要和环境限制。
6. 若测试失败，区分代码失败、环境失败和测试不稳定；不得将未运行说成通过。

## 输出
测试范围与用例、实际执行命令、通过/失败/未运行清单、失败原因与证据、剩余风险。

## 禁止
伪造测试结果；为通过测试删除有效断言；擅自访问生产数据或执行破坏性操作。
