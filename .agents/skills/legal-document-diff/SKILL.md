# 法律文件版本比较
1. 确认基准版本、目标版本、日期、签署状态和附件是否齐全。
2. 对齐标题、条款编号、定义、表格、附件和交叉引用。
3. 分类标记新增、删除、修改、移动和格式变化。
4. 对实质性变更说明可能影响，尤其是责任、付款、期限、终止、知识产权、保密和争议解决。
5. 不把纯格式变化误报为实质性法律变更；不因文本相同推断法律效果相同。
6. 输出需人工复核的歧义、缺失附件和编号错位。

输出：差异摘要、逐条变化、影响评估、引用位置和待确认问题。敏感文件不得未经授权传送到外部服务。
