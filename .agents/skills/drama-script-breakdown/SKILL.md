# 短剧剧本与制作拆解
1. 确认场景目标、角色、冲突、时长和制作限制。
2. 剧本按场次列出地点/时间、人物、动作、对白、情绪变化和转场。
3. 分镜逐条列镜头编号、景别、机位、画面动作、对白/音效、时长和转场。
4. 估算对白时长与镜头总时长，标注特效、群众演员、特殊道具和高成本场景。
5. 生成角色、场景、服化道和镜头清单，并关联到剧本段落。
6. 检查可拍摄性、连续性、预算风险和版权来源。

输出：剧本稿、分镜表、制作清单、成本/执行风险和待确认事项。未经实际制作不得声称已完成成片。
