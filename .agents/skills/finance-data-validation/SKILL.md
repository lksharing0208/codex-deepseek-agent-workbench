# 金融数据校验
1. 标记数据源、授权范围、抓取时间、市场时区和延迟。
2. 核对资产代码、市场、币种、单位、复权方式、财报期间和同比/环比口径。
3. 检查缺失值、重复行、异常跳变、非交易日和时间戳错位。
4. 对关键数值与第二来源交叉验证；记录冲突，不擅自挑选有利数据。
5. 对指标计算保留公式、输入字段和样本区间。
6. 关键数据未通过校验时，阻止生成伪精确交易建议。

输出：数据清单、时间戳、口径、质量问题、交叉验证结果和可用性结论。禁止将延迟行情标为实时、将缺失值推断为零或伪造数据。
