# 短剧连续性审查
1. 建立角色状态表：目标、关系、知识边界、伤病、服装和关键物品。
2. 按时间线检查事件顺序、地点移动、年龄/日期和场景衔接。
3. 检查人物是否知道尚未获知的信息，行为是否符合既有动机。
4. 检查世界观规则、道具去向、承诺、伏笔和回收。
5. 区分确定矛盾、潜在矛盾和需要编剧确认的模糊点。
6. 为每个问题给出具体集数/场次、证据和最小修复建议。

输出：问题清单、严重度、对应位置、影响和修复建议。不要静默修改会改变人物动机或主线的关键内容。
