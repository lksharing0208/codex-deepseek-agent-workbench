# 短剧选题与概念开发
1. 汇总已确认条件和待确认假设。
2. 提出差异化概念，包含一句话梗概、受众情绪价值、主角目标、核心冲突和卖点。
3. 评估开场吸引力、持续冲突、角色成长、制作成本、平台适配和版权风险。
4. 解释评分维度和依据，避免没有证据的市场热度结论。
5. 推荐主方案和备选方案，说明待验证的商业假设。

输出：概念卡、受众、差异化、主要冲突、分集延展性、制作风险和待验证假设。不得把主观评分描述为市场验证结果，也不得未经授权复刻受保护作品的独特表达。
