# 写作事实核查
1. 提取可核查的事实主张、数字、引文、人名、日期和因果表达。
2. 为每条主张寻找直接证据，优先官方或原始来源。
3. 核对上下文、单位、时间范围、样本、版本和适用范围。
4. 区分已证实、部分支持、存在争议、未找到证据和明显错误。
5. 检查引文准确性及链接是否真正支持主张。
6. 给出最小修改建议，将无法确认的内容标记为待核实。

输出：事实主张、证据链接、核查状态、建议改写和待核实项。未找到证据不自动等于虚假。
