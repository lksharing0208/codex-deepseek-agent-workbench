# 写作研究简报
1. 将主题拆成可验证的问题和所需证据。
2. 优先一手、官方、原始资料；必要时用可靠二手来源交叉核对。
3. 记录标题、发布机构/作者、发布日期、链接、访问日期和支持的主张。
4. 对数字、日期和冲突说法进行交叉验证。
5. 标记来源质量、证据缺口和可能过时的信息。
6. 区分事实、解释、观点和假设，形成证据矩阵。

输出：研究问题、关键发现、证据矩阵、来源清单、冲突信息和待核实项。禁止编造论文、链接、引用或统计数据。
