# 短剧分集大纲
1. 明确全剧核心问题、主角目标、对手力量、主要关系和结局方向。
2. 设计引爆事件、目标建立、升级、反转、低谷、决战和结局。
3. 为每集写明目标、冲突、关键行动、情绪变化、新信息和集尾钩子。
4. 检查每集是否推动主线或人物关系，避免重复冲突和无效拖延。
5. 建立伏笔清单，注明埋设集、回收集和回收方式。
6. 检查时间线、人物知识边界、动机和因果关系。

输出：全剧梗概、人物弧线、分集表、每集钩子、伏笔表和连续性风险。每集都应产生可说明的变化；重要反转应有铺垫。
