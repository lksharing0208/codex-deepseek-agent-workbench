# 交易计划与复盘
1. 记录交易前计划：依据、入场条件、仓位、退出条件、风险预算和不交易条件。
2. 收集实际委托/成交、时间戳、价格、数量、费用和市场环境；区分用户输入与外部数据。
3. 比较计划与实际执行，标记偏差及可验证原因。
4. 计算收益、成本、最大不利变动、风险暴露和规则遵守率，说明公式。
5. 区分策略问题、执行问题、数据问题和随机波动。
6. 形成下一次可验证的改进假设，不因单次盈亏直接修改规则。

输出：计划与实际对照、指标、偏差原因、风险事件和下一轮改进实验。默认只读，不提交或修改订单。
